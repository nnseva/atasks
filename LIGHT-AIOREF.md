# Облегченная ссылка для клиента atask

Клиент atask может сгенерировать прямой вызов обращения к узлам atasks. Облегченная ссылка генерируется динамически, по имени atask, например:

```python
atask_name = 'the_best_answer_to_any_question'

return_value = await ataskref[name](42)
```

Облегченная ссылка не регистрирует обработчик, она лишь позволяет обратиться к atask по имени, без импорта модуля с atask декларированным обычным образом - через декоратор.

Если возможно и не приведет к нежелательным последствиям, ataskref можно было бы совместить с декоратором atask:

```python
return_value = await atask[name](42)
```
